## Wanderly Travel (demo project)

Static, bilingual (EN/ID) travel-agency landing page with a WhatsApp-based booking form. All content (packages, prices, contacts) is dummy data.

- Run: serve the folder with any static server (ES modules need `http://`, not `file://`), e.g. `python -m http.server 8000`.
- Test: `npm test` (Node ≥ 20, no dependencies).
- Edit content: `js/data/packages.js` (prices, days), `js/data/site.js` (contact), `js/locales/{en,id}.js` (all text).
